# Deterministic Agent Harness (Zero-Drift Runtime)

A production-grade, framework-free agent runtime in plain TypeScript. It eliminates context window poisoning, premise propagation failures, and token runaway across long-horizon workflows using deterministic scratchpad eviction and pointer-based memory.

---

### The Problem: Compounding Failure in Swarms

Most agent architectures (CrewAI, AutoGen, raw ReAct loops) fail at scale due to **Context Compaction Drift**:
1. **Scratchpad Accumulation:** Retrying tools and intermediate JSON dumps bloats context to 40,000+ tokens by step 15.
2. **Cascading Hallucinations:** When downstream nodes read unvalidated opinions from earlier steps, a single incorrect verdict compounds into systematic pipeline collapse ($0.90 \times 0.85 \times 0.88 \dots$).
3. **Infinite Feedback Loops:** Agents repeat failing tool queries without hardware-level cycle detection.

### Architectural Invariants

* **Scratchpad Eviction ($O(1)$ Memory):** Every step starts with a clean context. Raw tool outputs, terminal chatter, and reasoning tokens are flushed from memory immediately after execution.
* **Invariant Schema Gatekeeping:** The model cannot write unvalidated free-form text to the global state. All mutations must satisfy a step-specific Zod schema with a single backpressure retry before hard termination.
* **Pointer Memory Externalization:** Payloads exceeding 250 bytes (e.g., Step 2's CSV dump) are written directly to isolated disk storage (`/tmp/run_*`). Prompts receive only SHA-256 hashes, schemas, and file paths.
* **State Transition Signatures:** A cryptographic hash of `(stepName, canonicalInput, stateVersion)` prevents infinite loops before tools are called.
